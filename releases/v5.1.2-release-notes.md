# MySQL MCP v5.1.2

## Highlights

- **Strict Read-Only SQL Enforcement**: Strips leading SQL comments and switches to explicit verb allowlisting on read paths, preventing comment-prefixed write statements from bypassing read/write scope separation.
- **Uniform Filter Validation**: Enforces `validateWhereClause` across every statistics and shell export tool, blocking unauthorized file access and subquery exfiltration in `WHERE` filters.
- **Hardened Container & Dependency Stack**: Updates core runtime packages, pins GitHub Action SHAs, and strips redundant package managers from the production Docker image to reduce attack surface.

## Security

- **Read-Only Query Classification (`GHSA-48f7-q6mc-23mp`)**: Fixed a read-only enforcement bypass where leading SQL comments (`--`, `#`, `/* ... */`, `//`) or MySQL/MariaDB conditional executable comments (`/*! ... */`, `/*M! ... */`) allowed write statements to execute under `read` scope in `mysql_read_query` and `mysql_explain`. Reported by **bebold6133**.
- **Uniform `WHERE` Clause Validation**: Added strict `validateWhereClause` checks to all statistical analysis (`stats/outlier`, `stats/advanced`, `stats/correlation`, `stats/descriptive`, `stats/percentiles`, `stats/distribution`, `stats/hypothesis`) and shell export (`mysqlsh_export_table`, `mysqlsh_dump_tables`) tools, and expanded blocked patterns to reject `INTO DUMPFILE`.
- **Container & Dependency Hardening**: Updated runtime and build dependencies, migrated dependency overrides to `pnpm-workspace.yaml`, and hardened the multi-stage `Dockerfile` to eliminate bundled `npm`/`corepack` vulnerabilities.

## Changed

- **Observability & HTTP Security**: Updated OpenTelemetry instrumentation version metadata and refined HTTP security header and logger handling for stricter type safety.

## Fixed

- **E2E Test Isolation**: Assigned dedicated ports to streaming and tool-filter Playwright E2E suites and added fast-fail server exit detection to eliminate port collisions in CI.

## Removed

- **Legacy Agentic Workflows**: Removed redundant `gh-aw` health monitor and maintenance workflows in favor of deterministic CI checks.
