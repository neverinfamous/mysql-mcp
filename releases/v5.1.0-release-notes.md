# MySQL MCP v5.1.0

## Highlights

- **Streamlined Observability**: Introduced the `mysql_setup_observability` prompt, drastically simplifying the initial configuration of Datadog and Grafana Alloy metrics.
- **Native Schema Alignment**: Upgraded schema generation to natively support the Model Context Protocol JSON schema formatting, removing legacy dependencies and ensuring full Zod 4 compatibility.

## Added

- **Prompts**: Added a dedicated `mysql_setup_observability` prompt to simplify setup workflows.
- **Observability**: Synced the latest, optimized Datadog dashboards for tracking tool performance and infrastructure health.

## Changed

- **Schema**: Replaced `zod-to-json-schema` with native MCP standard protocol support, fixing Zod 4 incompatibilities.
- **Linting**: Refactored the codebase to resolve rule suppressions, significantly improving type safety and maintainability.
- **Dependencies**: Upgraded core project dependencies to their latest stable releases, addressing necessary security patches.

## Fixed

- **Prompts**: Removed unnecessary arguments from the `mysql_setup_observability` prompt to prevent validation failures during parameterless invocation.
- **CI**: Corrected strict mode enforcement and automatically updated CI test badges.
- **Scripts**: Synced the correctly toggled `super_read_only` script for development workflows.

## Install

```bash
npm install -g @neverinfamous/mysql-mcp@5.1.0
docker pull writenotenow/mysql-mcp:v5.1.0
```
